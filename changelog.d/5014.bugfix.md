langgraph-agent `research_subtopic` now measures each subagent's deadline from when its worker thread actually begins, instead of using a single shared timer that could falsely mark queued subtopics as timed out (#5014, Option A). A new safety cap (`OVERALL_SUBAGENT_BUDGET_SECONDS`) prevents a genuinely hung worker from blocking the lead forever, and the "timed out" message now reports the subagent's actual elapsed time and clearly distinguishes a real per-task hang from an overall-budget cancellation. The subagent worker pool size (`MAX_SUBAGENT_WORKERS`, was hard-coded to 4) is now user-configurable via `LDR_LANGGRAPH_AGENT_SUBAGENT_MAX_WORKERS` for ollama / lmstudio / llama.cpp deployments that expose their own parallelism knob.
